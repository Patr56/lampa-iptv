# lampa-iptv (tv.team fork)

Форк плагина IPTV для Lampa (`https://cub.red/plugin/iptv`) под плейлист tv.team.
Собирается автоматически: GitHub Actions раз в сутки берёт свежий оригинал и накладывает правки из `patch.py`.
Если правка не легла (авторы поменяли код), сборка падает, опубликованная версия остаётся прежней, GitHub присылает письмо.

Правки:
- каналы без внутреннего `id` используют `tvg-id` (при логине в CUB сервер теряет id → не было программы);
- плейлист разбирается на устройстве, а не на сервере CUB;
- XMLTV без атрибутов (`<title>`, `<desc>`, `<display-name>` без `lang`, как у epg.team);
- телегид держится в памяти (−12 ч…+48 ч) и грузится при каждом запуске;
- если ссылка на телегид не задана — используется `https://epg.team/3.1.xml.gz`;
- в меню пункт называется «IPTV TT <версия оригинала>»; отладка — Консоль → вкладка TT.

Установка: Настройки → Расширения → Добавить плагин → `https://patr56.github.io/lampa-iptv/iptv.js`.
